# CBE Birr Plus Clone UI

## Introduction

This project is a UI clone of the CBE Birr Plus payment app, built using Flutter. The goal of this project is to replicate the user interface of the popular payment app and demonstrate the capabilities of Flutter for building beautiful and responsive UIs.
